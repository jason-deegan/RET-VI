# R functions

Reusable analytical functions will be separated into:

- `data/` — ingestion and source-specific processing
- `geography/` — geographic identifiers, crosswalks and boundary handling
- `indicators/` — indicator construction and standardisation
- `index/` — RET-VI calculation
- `scenarios/` — scenario transformations and assumptions
- `validation/` — checks and diagnostics
- `utilities/` — shared helper functions
